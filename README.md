
# UrbanVerse – Mini City Simulator

Welcome to **UrbanVerse!** A mini city simulator made in C that helps users explore different facilities and get updates about everyday city issues in Karachi.

The project currently focuses on two areas: **Clifton** and **Tariq Road**.

## What Can You Do in UrbanVerse?

The simulator has five main sections:

- **Transportation:** Explore public buses, rickshaws, ride-hailing services, cycling and walking options.
- **Healthcare:** Find nearby hospitals, medical clinics and pharmacies.
- **Entertainment:** Explore parks, outdoor places, cinemas, malls and gaming zones.
- **Restaurants:** Discover Pakistani, Chinese and fast-food options.
- **City Crisis Updates:** Check area-based water supply timings, gas supply timings, traffic updates and power supply timings.

## Extra Features

- Personalised welcome using the visitor's name.
- Choose between Clifton and Tariq Road.
- Save the visitor's profile.
- Keep a record of previous visits.
- View a visit summary for the current session.
- Navigate between sections using simple menus.

## How to Run

1. Download or clone the project.
2. Open the `.c` source file in Dev-C++ or another compatible C IDE.
3. Compile and run the program.
4. Enter your name.
5. Select your area: Clifton or Tariq Road.
6. Explore the different sections through the main menu.

**Note:** This project uses `windows.h` for console colours, so it is designed for Windows.

## Files Created

The program automatically creates these files when needed:

- `profile.txt` – Stores the last visitor's name and selected area.
- `visit_history.txt` – Stores the visitor's activity history.

## A Small Note

UrbanVerse is an educational mini-project. The crisis timings and traffic updates are sample information for demonstration purposes, not live or officially verified city updates.
